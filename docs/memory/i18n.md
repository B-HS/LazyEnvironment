# i18n 체계 (ko / en / ja + 언어팩 확장)

## 구조

- **단일 파일**: `app/LazyEnvironment/Resources/Localizable.xcstrings` (285키, 소스 언어 en — 키 자체가 영어 원문).
- UI 크롬 + **레시피 콘텐츠(summary/manualSteps/외부 후보 label/액션 타이틀 Prepare·Relocate·Clean Up)** 전부 이 파일에서 번역.
- 레시피 콘텐츠는 `Text(LocalizedStringKey(<JSON 문자열>))`로 렌더 → **xcstrings 키 = builtin-recipes.json의 영문 원문과 byte-identical**해야 매칭. 어긋나면 크래시 없이 영어 폴백.
- 인앱 언어 선택: 설정 > 언어(시스템/한국어/English/日本語) → `.environment(\.locale, ...)` 주입(재시작 불필요). `LanguageOption`(AppSettings.swift).

## 새 언어 추가 절차 (언어팩 PR 흐름)

1. xcstrings의 **모든 키**에 `"<lang>": {"stringUnit": {"state": "translated", "value": "..."}}` 추가 (기존 en/ko/ja 불변).
2. `AppSettings.swift`의 `LanguageOption`에 케이스 추가 + `SettingsView` 피커에 항목 추가.
3. 검증: 포맷 지정자(%@·%d) 키와 개수 일치 확인 → 빌드 → 빌드 산출물 `<lang>.lproj/Localizable.strings` 엔트리 수가 ko와 동일한지 → settings.json `language` 강제 후 라이브 렌더 캡처.

## 번역 규칙

- 제품·도구명(nvm, SDKMAN, Homebrew, uv...), 백틱 명령/플래그/경로/env명, `{{토큰}}`, 포맷 지정자, 곡선따옴표 verbatim 유지. 브랜드 "Lazy Environment" 그대로.
- 어투: ko 존댓말, ja です・ます調. "Copy export lines" 버튼 참조 표기: ko "export 구문 복사", ja 「export 行をコピー」.
- 인터폴레이션 매핑: String→%@, Int→%lld, Int32→%d, Text→%@. 숫자만 있는 키(%lld 단독)는 등록하지 않음.

## 대량 편집 패턴

python3로 json.load → `cat['strings'][key] = {"extractionState":"manual","localizations":{...}}` → `json.dump(..., ensure_ascii=False, indent=2)`. `plutil -lint`는 이 머신에서 JSON을 거부하므로 **`plutil -convert json -o /dev/null`로 검증**.
